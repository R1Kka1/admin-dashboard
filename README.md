# Admin Dashboard

基于 React + Vite 开发的后台管理系统。

## 技术栈

- React
- JavaScript / TypeScript
- React Router
- Axios
- JSON Server
- Recharts
- Dayjs

## 功能

- 用户登录
- 路由权限控制
- 商品管理 CRUD
- 用户管理 CRUD
- 商品搜索
- 数据统计
- 弹窗表单
- 删除确认
- Axios 封装

## 运行

安装依赖：

npm install

启动：

npm run dev
